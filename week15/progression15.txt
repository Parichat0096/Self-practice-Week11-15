
ปล. เนื้อหาต่อไปนี้ส่วนมากเป็นการหาข้อมูลจาก ai

-การตั้งค่าและใช้งาน Keycloak
    1.สร้าง Keycloak instance
        เราสร้างตัวแปร keycloak ที่เชื่อมต่อกับ Keycloak server โดยกำหนด URL ของเซิร์ฟเวอร์, Realm ของผู้ใช้, และ Client ID ของแอป
        ข้อมูลเหล่านี้ทำให้เว็บรู้ว่าจะส่งผู้ใช้ไปล็อกอินกับ Keycloak ตัวไหน
    2.ฟังก์ชัน initKeycloak()
        เป็นฟังก์ชัน แบบ async ที่เริ่มการเชื่อมต่อกับ Keycloak
        ช้ onLoad: "login-required" เพื่อบังคับให้ผู้ใช้ล็อกอินทันทีถ้ายังไม่ได้ล็อกอิน
        ถ้าล็อกอินสำเร็จ จะสามารถเข้าถึง token ของผู้ใช้ และข้อมูลใน token เช่น preferred_username (ชื่อผู้ใช้) หรือ roles ของผู้ใช้
        ฟังก์ชันจะคืนค่า tokenParsed เพื่อให้เว็บแอปนำข้อมูลผู้ใช้ไปใช้งานต่อได้
    3.ฟังก์ชัน signOut()
        ใช้สำหรับ ล็อกเอาท์ผู้ใช้ ออกจาก Keycloak
        สามารถกำหนด redirectUri ให้เว็บพากลับไปยังหน้าใดหน้าหนึ่งหลัง logout
-dialog เป็น HTML element ที่ใช้สร้าง กล่องโต้ตอบบนเว็บ ใช้แสดงข้อความแจ้งเตือน, ฟอร์ม, หรือเนื้อหาเพิ่มเติมโดยไม่ต้องโหลดหน้าใหม่
-Modular JS  เป็นการแบ่งฟังก์ชันและ import/export
