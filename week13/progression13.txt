-ดึงข้อมูลจาก Backend หน้าเว็บไม่ได้มีข้อมูลเอง ต้องไปขอจาก backend ด้วย fetch
    ถ้าดึงมาสำเร็จ → เอามาใช้บนหน้าเว็บ
    ถ้าดึงไม่ได้ → ต้องขึ้น error ให้ผู้ใช้รู้ 
-ข้อมูลจาก backend จะมาเป็น JSON เวลา backend ส่งข้อมูลมา เราจะแปลงด้วย .json() แล้วเอาค่าที่ได้
    เช่น id, planCode, nameTh ไปใช้แสดงผลในหน้าเว็บ
-สร้าง UI จากข้อมูลด้วย JavaScript สามารถใช้ JS สร้าง element (เช่น <tr>, <td>) ตามจำนวนข้อมูลที่ได้มา
    โดยไม่ต้องเขียน HTML ซ้ำ ๆ เพราะ JS วนลูปสร้างให้หมด
-Vite รองรับหลายหน้า (Multi-Page) ถ้าโปรเจ็กต์ไม่ได้มีแค่หน้าเดียว เราต้องบอก Vite ว่าเรามีหลาย HTML 
    เช่น index.html, reserve.html เวลารัน dev หรือ build ก็จะใช้งานหลายหน้าได้เหมือนเว็บจริง
