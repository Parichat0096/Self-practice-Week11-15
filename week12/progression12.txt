-ความแตกต่างระหว่างsynchronousกับasynchronous -->
    synchronous : เป็นโปรแกรมที่ถ้าคำสั่งก่อนหน้ายังรันไม่เสร็จจะไม่รันคำสั่งถัดไปเด็ดขาด 
    asynchronous: เป็นโปรแกรมที่ไม่รอ ถ้าคำสั่งก่อนหน้าต้องรอก่อนถึงจะรันมันจะข้ามไปรันคำสั่งถัดไปเลย 
                   แล้วถ้าคำสั่งที่ต้องรอนั้นเสร็จมันค่อยกลับไปรันคำสั่งนั้น หรือก็คือ เสร็จก่อนรันก่อน

-promise --> เป็นโปรแกรมแบบasynchronous เป็นชื่อclassทีี่นำไปสร้างobject มีความซับซ้อนตรงที่ว่ามี 3 stateในการทำงาน 
              ตอนที่คำสั่งกำลังรอรันจะอยู่ในstate pending แล้วถ้ารันแล้วสำเร็จจะไปstate fulfilled แต่ถ้ารันแล้วไม่สำเร็จจะไปstate rejected
              ตัวfulfilledกับrejectedเราสามารถเอาไปเขียนเป็นฟังก์ชันต่อเพื่อจัดการผลจากการรันได้

-.then().catch --> จะทำให้asynchronousกลายเป็นsynchronous โดยตัว.then()จะเป็นตัวที่บอกให้รอโปรแกรมนี้รันก่อน ถ้ารันแล้วสำเร็จเข้าเงื่อนไงใน .then()
                    แต่ถ้าไม่ จะเข้าเงื่อนไขของ.catch

- async/await --> ก็เป็นการทำให้asynchronousกลายเป็นsynchronousโดยการบอกให้รอ awaitต้องใช้คู่กับasyncเสมอภายใต้ function ที่ถูกประกาศเป็น
                    function แบบ asynchronous

-rest api --> ทำให้สามารถติดต่อกับserverได้ ผ่านการส่งข้อมูลใน protocol. ข้อมูลในrest apiเป็น json

-fetch() --> เป็น function ที่ใช้เรียก HTTP request (เช่น GET, POST) และ return เป็น Promise โดยอัตโนมัติ

-json() --> เป็น function ที่ใช้แปลง json string เป็น object js เพื่อให้jsสามารถจัดการได้
